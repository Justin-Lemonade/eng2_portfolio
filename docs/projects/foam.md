# Styrofoam Cutter Project

## 1. Summary  
- Goal: build a hot-wire styrofoam cutter using nichrome wire for smooth, easy cuts.  
- Purpose: make set building for school plays faster and more precise.  
- Designs:  
  - **Table version** – base + overhead arm, nichrome wire hangs vertically.  
  - **Handheld version** – T-shaped handle with stretched wire at the end.  
- Power: wired to run voltage through nichrome, heating it enough to cut foam.  

## 2. Problems + Solutions  
- **Wire elongation when hot** → added a spring (table) or flexible sticks (handheld) to keep tension.  
- **Risk of burning wood** → positioned wiring so only the nichrome section heated.  
- **Indecisiveness / stalling** → solved by sticking to deadlines and just building to test ideas.  
- **Weak, brittle wood** → learned to pre-drill holes before inserting screws.  

## 3. What I Learned  
- **Technical skills**:  
  - First time soldering.  
  - More precise wood cutting and drilling.  
  - Importance of pre-drilling to avoid splitting.  
- **Non-technical lessons**:  
  - Delegation and task management are key.  
  - Sometimes you need to stop overthinking and just build.
